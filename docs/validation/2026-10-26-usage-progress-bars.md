## Result

Both account windows have independent `=` usage bars with the percentage after each bar on the same existing bottom line. Consumed cells and their percentage use `success` below 70%, `warning` from 70% to below 90%, and `error` at 90% or above. Remaining cells are dim. Text and color rendering share the same width selection and readings.

The renderer reserves 24 columns for Claude's native mode indicators and separators. The normal 10-cell bars shorten to 5, 2 or 1 cell before a numeric fallback. Missing or expired readings use question-mark cells and N/A; actual zeros remain explicit and over-limit values keep their percentage. No metric sources, token accounting, timers, network access, permissions or side panes were changed.

## Limits

Terminal colors follow the active theme. Bar fill is rounded to whole cells; the percentage remains the precise native reading rounded to at most one decimal. Extremely narrow terminals, unusually long values or extra host footer content can still clip the smallest numeric format; `/aikya-usage` returns the detailed report. No extra line is added to compensate.
