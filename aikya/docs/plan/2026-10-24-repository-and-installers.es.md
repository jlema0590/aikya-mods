**Tecnologías:** Bash compatible con macOS y Linux; Python estándar para las pruebas de instaladores; pruebas nativas de Claude para BoxBot.

## Restricciones

- Interfaz, ayuda, errores y documentación de uso en inglés.
- No modificar `sources/` ni el repositorio del núcleo Aikya.
- BoxBot conserva la cinta y las cajas sin controles visibles.
- Flow y Usage todavía no están implementados: se documentan como pendientes y no se ofrecen como plugins instalables, salvo ampliación explícita del alcance.
- No instalar en la configuración real del usuario durante las pruebas.
- `--scope user|project|local`, `--dry-run`, `--list`, `--all`, selección por nombres y menú por números.

## Revisión de riesgos

- Una selección inválida, incluso después de otra válida, no modifica la configuración.
- Cancelar o finalizar stdin sin selección no instala nada.
- Un fallo al registrar el marketplace impide instalar plugins.
- Rutas con espacios, selección repetida y propagación de fallos conservan argumentos y códigos de salida.
- Los plugins pendientes no se anuncian como disponibles.
