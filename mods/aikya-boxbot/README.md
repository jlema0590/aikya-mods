# Aikya BoxBot

Boxes move from left to right along a conveyor belt with turning rollers. BoxBot is an optional, decorative Claude Code mod. Its movement does not measure task completion, tokens, or tool success. All interface text and commands are in English.

## Install

From the repository root:

```sh
bash mods/aikya-boxbot/install.sh
```

For direct installation from the hosted marketplace in a Claude Code session:

```text
/plugin install aikya-boxbot --marketplace jlema0590/aikya-mods
```

Restart Claude Code after installation, then enter `/aikya-boxbot`. This repository is private; direct GitHub installation requires access.

## Try without installation

Requires Claude Code with mods support. Tested with Claude Code **2.1.308**.

From the directory containing this plugin:

```sh
claude --plugin-dir ./aikya-boxbot
```

Then enter:

```text
/aikya-boxbot
```

The panel displays the animation without buttons or on-screen controls. Escape closes it when Claude gives the pane keyboard focus. The loop starts only after an explicit command and stops when the panel closes or the session ends. Reopening preserves its position and playback choices. Playback remains available through the commands below.

## Terminal layout requirement

The agreed target is one terminal session split into Claude Code on the left and a native mod pane on the right. Once installed and enabled, the future startup integration should open that pane automatically when `claude` starts, keeping keyboard focus in Claude's prompt. Native panes require a sufficiently wide fullscreen terminal for side docking. A stacked pane in a narrow terminal is not the requested target layout.

This prototype currently opens through `/aikya-boxbot`. Automatic startup, visibility-aware pausing when switching native pane tabs, and the final side-docking checks are recorded in the implementation plan and have not been implemented here.

You can also use:

```text
/aikya-boxbot pause
/aikya-boxbot resume
/aikya-boxbot still
/aikya-boxbot motion
/aikya-boxbot hide
```

`still` displays stationary boxes on the conveyor belt. It is the native mod's manual reduced-motion option. The browser preview additionally honors `prefers-reduced-motion`; the mod does not claim to detect an operating-system preference that its API does not expose.

## Rendering and access

Desktop and VS Code use the native `Svg` element. The terminal uses a seven-row monospace drawing that fits the pane width. Three boxes travel at a constant speed in an eight-second loop sampled at eight frames per second. Boxes enter at the left edge and leave at the right edge; the belt and rollers move with them. The animation timer is cancelled while paused, in still mode, and when hidden. No model request, tool call, subprocess, network request, credential lookup, file read/write, or telemetry call is made by the mod.

The plugin registers its own command and observes its own pane closing plus session lifecycle. It does not modify prompts, permissions, other panes, or Aikya's execution state. `--plugin-dir` loads it for the session; the installer registers it through the Aikya Mods marketplace.

## Verify

```sh
claude plugin validate ./aikya-boxbot --strict
claude plugin test ./aikya-boxbot
```

The nine tests exercise opening, timer-driven updates, pause/resume, still mode, Desktop/VS Code element validation, closing/reopening, narrow layouts, conveyor movement, and loop continuity. Native surface tests validate element trees; they do not replace a manual session check of the final application paint.
