# Aikya Usage — planned

This directory reserves the independent Usage mod. It contains no executable plugin or installer and is not listed in the marketplace or install menu.

The planned English interface places Context, Tokens, and Usage together on one compact line below Claude Code's prompt. No persistent usage card occupies the right pane.

Example only:

```text
Context: 42% | Tokens: 53k | Usage 5h/7d: N/A/N/A
```

Context occupancy, accumulated token counts, estimated cost, and account quotas are different measurements. Missing quotas display N/A; quotas must never be inferred from token counts. Details are planned under `/aikya-usage`.

The telemetry normalization, request ledger, footer renderer, and historical bridge are not implemented.

Implementation reference: [original design](../../aikya/docs/plan/claude-mods-design.es.md).
