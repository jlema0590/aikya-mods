# Aikya Flow — planned

This directory reserves the independent Flow mod. It contains no executable plugin or installer and is not listed in the marketplace or install menu.

The planned English interface follows the active command and distinguishes pending, running, waiting, completed, failed, skipped, blocked, and interrupted states. The six Aikya phases are Explore, Plan, Implement, Validate, Security, and Review. Completed tool calls alone must never imply verified phase completion.

The target layout places Claude Code on the left and Flow plus BoxBot on the right, in the same terminal. A semantic bridge to Aikya's execution state and the combined pane have not been implemented.
